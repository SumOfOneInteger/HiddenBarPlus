# SumOfOneInteger/homebrew-tap

Homebrew tap for [Hidden Bar Plus](https://github.com/SumOfOneInteger/HiddenBarPlus),
a menu bar cleaner for macOS 13 and later, including macOS 27.

```sh
brew install --cask sumofoneinteger/tap/hidden-bar-plus
```

The cask here is published by the Hidden Bar Plus release workflow, or by
`scripts/publish-tap.sh` from the app repository. Please report problems in the
[app repository](https://github.com/SumOfOneInteger/HiddenBarPlus/issues).
